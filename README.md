# Personal Resume Website

A simple, responsive student resume website built with HTML and CSS.

## Files
- `index.html` — website content and sections
- `style.css` — colours, typography, layout, spacing, cards and responsive rules

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create or open your GitHub repository.
2. Upload `index.html` and `style.css` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and copy the live URL shown there.

Before submitting, replace the sample email address in `index.html` with your own.
